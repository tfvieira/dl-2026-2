## Usage guidelines

- Open the notebook using the **Open in Colab** badge.
- Save a copy to Google Drive before editing it.
- Execute the cells from top to bottom.
- Complete the sections marked with `START CODE HERE` and `END CODE HERE`.
- Modify the examples and exercises freely in your copy.

New notebooks will be added as the course progresses.
